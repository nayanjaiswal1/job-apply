# Goal

Build a personal job hunting agent that runs mostly on autopilot.

## What it does
- Finds jobs across LinkedIn, Naukri, Wellfound, Indeed, Internshala every 6h
- Scores each job against my resume
- Rewrites my resume and cover letter per job (human-sounding, ATS-optimised)
- Finds referrals at target companies and drafts DMs
- Sends recruiter emails and LinkedIn DMs via rate-limited queue
- Fills application forms via browser automation
- Watches my inbox for replies and updates application status
- Sends follow-ups on silence; preps interview Q&A per role
- Dashboard to approve, track, and review everything

## What it is not
- Not a mass-spam tool — daily caps enforced, every outreach human-approved
- Not a resume fabricator — rewrites only what the candidate already wrote
- Not cloud-hosted — runs locally, resumes/cover letters never leave the machine

## Done = daily use, mostly hands-off
I open the dashboard once a day to approve outreach and see replies. The rest runs on schedule.
